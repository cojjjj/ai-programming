# Local Setup Commands

Run these commands in Anaconda Prompt on Windows:

```powershell
conda create -n ai-agents python=3.11
conda activate ai-agents
python --version
```

Expected Python version: 3.11.x

Then open this project folder in VS Code.

## Important

Store your Gemini API key in a local `.env` file only.
Do not commit `.env` or your API key to GitHub.
